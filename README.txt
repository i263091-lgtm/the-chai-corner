- assets/final_chai.jpg  Original chai illustration supplied with Lab 11

HOW TO RUN
1. Extract the ZIP file.
2. Keep the three HTML files, style.css, script.js and assets folder together.
3. Open index.html in a web browser.
4. Use the navigation bar to move between Home, Menu and Gallery.

TECHNOLOGIES
Only HTML, CSS and vanilla JavaScript are used. No frameworks or external libraries.
